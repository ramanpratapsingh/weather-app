About Skyline

Why we built this

Skyline is a simple weather lookup app built as a college front-end project. It uses the free Open-Meteo API to fetch live temperature, wind speed and humidity for any city in the world — no sign-up or API key required.

How it works

When you search a city, Skyline first finds its coordinates using Open-Meteo's geocoding service, then requests the current weather for that location. Your last five searches are saved in your browser so you can revisit them quickly.

Tech Stack

Built entirely with HTML, CSS and JavaScript — no frameworks or backend server involved.
